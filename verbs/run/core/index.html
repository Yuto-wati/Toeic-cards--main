VERB SERIES: RUN

RUN のレベル別完全解説

コアイメージから難関大・ビジネスレベルまで全網羅

🎯 RUNのコアイメージ（基礎）

本質：「勢いよく進む・動く」

━━━→→→
（勢いのある動き）
🏃 走る
足で勢いよく移動する
💧 流れる
液体が勢いよく移動する
🏢 運営する
事業が勢いよく進む
⚙️ 作動する
機械が勢いよく動く
Level 1

📚 中学生レベルの語法

1. run（走る）

コアイメージ：足で「勢いよく移動する」動作

  • I run every morning.

    毎朝走ります。（毎朝勢いよく移動します）

  • He ran to the station.

    彼は駅まで走った。（彼が駅まで勢いよく移動した）

  • The children are running in the park.

    子供たちが公園で走っている。（子供たちが公園で勢いよく移動している）

ポイント：walk との違い walk = ゆっくり歩く
run = 速く走る

2. run（運営・経営する）

コアイメージ：事業を「勢いよく進める」

  • He runs a restaurant.

    彼はレストランを経営している。（彼がレストランを勢いよく進めている）

  • She runs her own business.

    彼女は自分の事業を運営している。（事業を勢いよく進めている）

  • Who runs this company?

    誰がこの会社を経営していますか？（誰がこの会社を勢いよく進めていますか）

ポイント：manage との違い run = 経営・運営（全体を動かす）
manage = 管理（細部を管理）

3. run（作動する、動く）

コアイメージ：機械が「勢いよく動く」

  • The engine is running.

    エンジンが動いている。（エンジンが勢いよく動いている）

  • My computer won't run.

    コンピューターが動かない。（コンピューターが勢いよく動かない）

  • This program runs on Windows.

    このプログラムはWindowsで動く。（Windowsで勢いよく動く）

ポイント：work との違い run = 動作する（継続的な動き）
work = 機能する（結果を出す）

4. run（流れる）

コアイメージ：液体が「勢いよく移動する」

  • Water runs from the tap.

    水道から水が流れる。（水道から水が勢いよく移動する）

  • Tears ran down her face.

    涙が顔を流れた。（涙が顔を勢いよく移動した）

  • The river runs through the city.

    川が街を流れている。（家が街を勢いよく移動している）

ポイント：flow との違い run = 勢いよく流れる
flow = ゆったり流れる

5. run out（尽きる、なくなる）

コアイメージ：「外へ勢いよく出て」なくなる

  • We're running out of time.

    時間がなくなってきた。（時間が外へ勢いよく出ている）

  • The milk ran out.

    牛乳がなくなった。（牛乳が外へ出て尽きた）

  • I've run out of money.

    お金が尽きた。（お金が外へ出て尽きた）

ポイント：out = 外へ・尽きる 「在庫切れ」のイメージ
Level 2

🎓 高校生レベルの語法

1. run into

コアイメージ：「〜の中へ勢いよく進んで」ぶつかる

意味1：偶然会う

I ran into an old friend.

旧友にばったり会った。（旧友の中へ勢いよく進んだ）

意味2：衝突する

The car ran into a tree.

車が木に衝突した。（木の中へ勢いよく進んだ）

意味3：問題に直面する

We ran into problems.

問題に直面した。（問題の中へ勢いよく進んだ）

ポイント：into = 中へ。meet by chance と同義。

2. run away

逃げる、家出する（「離れた場所へ勢いよく進む」）

  • The thief ran away.

    泥棒が逃げた。（泥棒が離れた場所へ勢いよく進んだ）

  • Don't run away from your problems.

    問題から逃げるな。（問題から離れた場所へ勢いよく進むな）

  • She ran away from home.

    彼女は家出した。（彼女が家から離れた場所へ勢いよく進んだ）

ポイント：away = 離れて。escape と同義。

3. run over

コアイメージ：「上を越えて勢いよく進む」

意味1：車でひく

He was run over by a car.

彼は車にひかれた。（車によって上を越えて進まれた）

意味2：時間を超過する

The meeting ran over.

会議が時間を超過した。（会議が上を越えて進んだ）

意味3：ざっと見直す

Let me run over the plan.

計画をざっと見直させて。（計画の上を勢いよく進ませて）

ポイント：over = 上を越える。「越境」のイメージ。

4. run across

偶然見つける、ばったり会う（「横切って勢いよく進んで」出会う）

  • I ran across an old photo.

    古い写真を偶然見つけた。（古い写真を横切って勢いよく進んだ）

  • I ran across him at the mall.

    モールで彼にばったり会った。（モールで彼を横切って勢いよく進んだ）

  • You might run across some difficulties.

    困難に出くわすかもしれない。（困難を横切って勢いよく進むかもしれない）

ポイント：across = 横切って。run into と同義。

5. run through

コアイメージ：「貫通して勢いよく進む」

意味1：復習する

Let's run through the presentation.

プレゼンを復習しよう。（プレゼンを貫通して勢いよく進もう）

意味2：使い果たす

He ran through his savings.

彼は貯金を使い果たした。（貯金を貫通して勢いよく進んだ）

意味3：貫く

A sword ran through his body.

剣が体を貫いた。（剣が体を貫通して勢いよく進んだ）

ポイント：through = 貫通。「最初から最後まで」のイメージ。

6. run up

コアイメージ：「上方向へ勢いよく進む」

意味1：駆け上がる

He ran up the stairs.

彼は階段を駆け上がった。（階段を上方向へ勢いよく進んだ）

意味2：借金が積み上がる

He ran up a huge debt.

彼は巨額の借金を作った。（借金を上方向へ勢いよく進めた）

意味3：急いで作る

She ran up a dress.

彼女はドレスを急いで作った。（ドレスを勢いよく上方向へ進めた）

ポイント：up = 上方向・増加。「急速な増加」のイメージ。

7. run down

コアイメージ：「下方向へ勢いよく進む」

意味1：駆け下りる

He ran down the hill.

彼は丘を駆け下りた。（丘を下方向へ勢いよく進んだ）

意味2：電池が切れる

The battery has run down.

電池が切れた。（電池が下方向へ勢いよく進んだ）

意味3：批判する・けなす

Don't run him down.

彼を批判するな。（彼を下方向へ勢いよく進めるな）

意味4：車でひく

The dog was run down.

犬がひかれた。（犬が下方向へ勢いよく進まれた）

ポイント：down = 下方向・減少。「低下・衰退」のイメージ。

8. run by

説明する、確認する（「そばを勢いよく通って」見せる）

  • Let me run this by you.

    これを説明させて。（これをあなたのそばを勢いよく通らせて）

  • Can I run an idea by you?

    アイデアを聞いてもらえますか？（アイデアをあなたのそばを通してもいいか）

  • Run it by me again.

    もう一度説明して。（それを私のそばをもう一度）

ポイント：by = そばを通る。「提示・確認」のニュアンス。

Level 3

🏆 難関大学合格レベルの語法

1. run out on

見捨てる、裏切る

He ran out on his family.

家族から外へ勢いよく出た。abandon と同義。

2. run for

〜に立候補する

He's running for president.

大統領に向かって勢いよく進んでいる。「選挙出馬」。

3. run in the family

家系に伝わる

Musical talent runs in the family.

家族の中を勢いよく進んでいる。「遺伝」。

4. run short of

〜が不足する

We're running short of time.

時間が短く勢いよく進んでいる。「不足・欠乏」。

5. run counter to

〜に反する

This runs counter to our policy.

方針に対抗して勢いよく進む。contradict と同義。

6. run the risk of

〜の危険を冒す

You run the risk of losing everything.

危険の中を勢いよく進んでいる。risk と同義。

7. run its course

自然に終わる

The relationship ran its course.

経過を勢いよく進んだ。「自然な終わり」。

8. run a fever

熱がある

I'm running a fever.

熱を勢いよく進めている。have a fever と同義。

TOEIC

💼 TOEIC頻出ビジネス英語の語法

1. run a business

事業を経営する

He runs a successful business.

2. run smoothly

順調に進む

Everything is running smoothly.

3. run behind schedule

予定より遅れる

We're running behind schedule.

4. run on time

時間通りに進む

The train runs on time.

5. run a test

テストを実施する

We need to run a test.

6. run an advertisement

広告を掲載する

We'll run an ad in the paper.

7. run a meeting

会議を進行する

She runs the weekly meetings.

8. run an errand

用事を済ませる

I need to run an errand.

9. run efficiently

効率的に動く

The system runs efficiently.

10. run a program

プログラムを実行する

Run the program again.
