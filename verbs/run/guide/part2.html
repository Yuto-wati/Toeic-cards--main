RUN Part 2

多義語・慣用表現・熟語 (66-130)

run at a profit黒字経営するTOEIC頻出
コアイメージ
💰 ━━→→→ ✅
利益が出ている状態で動く

The company is finally running at a profit.

その会社はようやく黒字経営になっています。

We aim to run the new branch at a profit within a year.

1年以内に新支店を黒字化することを目指しています。

Point：

損失を出さず、利益を上げながら運営している状態。

run on a budget限られた予算内で運営する
コアイメージ
🪙 ━━→→→ [Budget]
予算という枠組みの上で動く

The project is being run on a tight budget.

そのプロジェクトは厳しい予算内で運営されています。

It's difficult to run a department on such a small budget.

そのような少ない予算で部署を運営するのは難しいです。

Point：

潤沢な資金ではなく、決まった予算の範囲内でやりくりすること。

run on schedule予定通りに運行・進行するTOEIC頻出
コアイメージ
📅 ━━→→→ [Schedule]
予定という線の上を動く

The trains are running on schedule today.

今日の電車は予定通りに運行しています。

Is the renovation project running on schedule?

リフォーム計画は予定通りに進んでいますか？

Point：

遅延なく、決められたスケジュール通りに物事が進んでいること。

run by the rules規則に従って運営する
コアイメージ
⚖️ ━━→→→ [Rules]
ルールによって動かされる

The organization is run strictly by the rules.

その組織は厳格に規則に従って運営されています。

We must run the competition by the official rules.

大会は公式ルールに則って運営しなければなりません。

Point：

独自の判断ではなく、既存の規則を遵守して物事を進めること。

run according to plan計画通りに進む
コアイメージ
🗺️ ━━→→→ [Plan]
計画に一致して動く

Thankfully, everything is running according to plan.

ありがたいことに、すべてが計画通りに進んでいます。

The product launch ran according to plan.

製品の発売は計画通りに進みました。

Point：

予期せぬトラブルなく、当初の計画と一致して進行すること。
