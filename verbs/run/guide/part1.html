RUN PHRASAL VERBS

RUN 句動詞 完全解説【前編】

基本イメージから日常会話表現まで（Section 1〜3）

🎯 RUNのコアイメージ（基礎）

本質：「勢いよく進む」

●━━━━━━→
（勢いよく）

このイメージから派生する全ての意味：

  • 駆ける：人や動物が勢いよく走る
  • 流れる：液体が勢いよく移動する
  • 動かす：機械や組織を稼働させ続ける
  • 続く：線や時間が勢いよく伸びる
Section 1

基本・最優先（ここだけは完璧に）

1. run

走る

コアイメージ

👤━━→→→

She ran to catch the bus.

彼女はバスに間に合うよう走りました。

The children are running around the playground.

子供たちが遊び場を走り回っています。

ポイント：最も基本的な意味。身体を使った素早い移動を表します。
