RUN PHRASAL VERBS

RUN 句動詞 完全解説

基本イメージから日常会話表現まで（Section 1〜3）

🎯 RUNのコアイメージ（基礎）
本質：「勢いよく進む」
●━━━━━━→
（勢いよく）

このイメージから派生する全ての意味：

  • 駆ける：人や動物が勢いよく走る
  • 流れる：液体が勢いよく移動する
  • 動かす：機械や組織を稼働させ続ける
  • 続く：線や時間が勢いよく伸びる
1 基本・最優先（ここだけは完璧に）
run走る
コアイメージ
👤━━→→→
（人が勢いよく移動）

I run every morning in the park.

私は毎朝公園で走ります。

She ran to catch the bus.

彼女はバスに間に合うよう走りました。

The children are running around the playground.

子供たちが遊び場を走り回っています。

Point：

最も基本的な意味。身体を使った素早い移動を表します。

run（運営する）経営する、運営するTOEIC頻出
コアイメージ
🏢━━→→→
（組織が継続的に動く）

My father runs a small restaurant.

父は小さなレストランを経営しています。

She runs the marketing department.

彼女はマーケティング部門を運営しています。

Who runs this company?

この会社は誰が経営しているのですか？

Point：

ビジネスや組織を「継続的に動かす」というニュアンス。

run（作動する）動く、作動するTOEIC頻出
コアイメージ
⚙️━━→→→
（機械が継続的に動く）

The machine runs smoothly.

その機械は順調に動いています。

My car runs on electricity.

私の車は電気で動きます。

The program is running in the background.

プログラムがバックグラウンドで動いています。

Point：

機械やシステムが「作動している状態」を表します。

run（流れる）流れる
コアイメージ
💧━━→→→
（液体が勢いよく流れる）

Water runs from the tap.

水が蛇口から流れ出ています。

Tears ran down her cheeks.

涙が彼女の頬を流れ落ちました。

The river runs through the city.

その川は街を流れています。

Point：

液体の継続的な流れを表現します。

run out尽きる、なくなるTOEIC頻出
コアイメージ
📦 → → → 💨
（外へ出て行って空になる）

We've run out of milk.

牛乳が切れてしまいました。

My patience is running out.

私の我慢が限界に近づいています。

Time is running out.

時間がなくなってきています。

Point：

「中から外へ出て行って空になる」イメージ。日常会話で非常に頻繁に使われます。

run out of〜を切らす、〜がなくなるTOEIC頻出
コアイメージ
📦 → → → 💨 [何か]
（特定のものが外へ出て空になる）

We ran out of paper.

紙を切らしてしまいました。

Don't run out of gas on the highway.

高速道路でガス欠にならないように。

The store has run out of that product.

その店はその製品を切らしています。

Point：

"run out"に目的語を付ける形。何が尽きたかを明確に示します。

run intoばったり会う、衝突する、〜に達するTOEIC頻出
コアイメージ
━━→ 💥 [対象]
（勢いよく進んで何かにぶつかる）

I ran into an old friend yesterday.

昨日、旧友にばったり会いました。

The car ran into a tree.

車が木に衝突しました。

The cost ran into thousands of dollars.

コストは数千ドルに達しました。

Point：

「進んでいって何かに当たる」が基本。偶然の出会いや衝突、金額の到達を表します。

run away逃げる、家出する
コアイメージ
👤 ← [場所] → → →
（その場から離れて逃げる）

The thief ran away before the police arrived.

泥棒は警察が到着する前に逃げました。

Don't run away from your problems.

問題から逃げないでください。

The dog ran away from home.

その犬は家から逃げ出しました。

Point：

物理的な逃走だけでなく、比喩的に「問題から逃げる」という意味でも使われます。

run overひく、はねる、超過するTOEIC頻出
コアイメージ
━━→ 🚗 → →
⬇️
（上を越えて通過する）

The car ran over a cat.

車が猫をひきました。

The meeting ran over by 30 minutes.

会議は30分超過しました。

Let me run over the main points again.

要点をもう一度ざっと見直させてください。

Point：

「上を越える」イメージから、物理的な接触、時間超過、素早い確認など多様な意味が派生します。

run across偶然見つける、ばったり会う
コアイメージ
━━→ ✕ [対象]
（道を横切る時に偶然出会う）

I ran across an interesting article in the newspaper.

新聞で面白い記事を偶然見つけました。

He ran across his former teacher at the airport.

彼は空港でかつての先生にばったり会いました。

Point：

"run into"と似ていますが、より「（場所を）横切る」際に遭遇するニュアンスが含まれます。

run through通す、使い果たす、復習するTOEIC頻出
コアイメージ
━━→ [対象] → →
（通り抜けて駆け抜ける）

Let's run through back the schedule for tomorrow.

明日のスケジュールをざっと確認しましょう。

He ran through his inheritance in just a year.

彼はたった一年で遺産を使い果たしました。

A cold shiver ran through my body.

体に冷たい戦慄が走りました。

Point：

何かを「突き抜けて走る」イメージ。ビジネスでは「ざっと確認する」という意味で頻出です。

run up駆け上がる、積み上がるTOEIC頻出
コアイメージ
↗️↗️↗️ ━━→ 📈
（上に向かって勢いよく増える）

He ran up a huge credit card bill.

彼はクレジットカードの請求額を膨らませてしまいました。

The boy ran up the stairs to his room.

男の子は自分の部屋まで階段を駆け上がりました。

Point：

「上へ」の勢いから、物理的な上昇だけでなく、借金などが急激に増えることも表します。

run down駆け下りる、電池が切れる、批判する
コアイメージ
━━→ 📉 ↘️↘️↘️
（下に向かって勢いが落ちる）

The battery has run down; I need to charge it.

電池が切れました。充電する必要があります。

She ran down the hill to the lake.

彼女は湖の方へ丘を駆け下りました。

You shouldn't run down your colleagues.

同僚をけなすべきではありません。

Point：

「下へ」の勢いから、物理的な下降、エネルギーの低下、評価を下げる（けなす）へと繋がります。

run by〜に説明する、確認するTOEIC頻出
コアイメージ
━━→ 👤 [アイデア]
（誰かのそばに案を通してみる）

Can I run a few ideas by you?

いくつかアイデアを説明して、確認してもらえますか？

I'll need to run this by my boss first.

まず上司にこれを確認する必要があります。

Point：

"by"は「〜のそば」を意味し、案を誰かのそばにサッと通して反応を見るイメージです。

run along立ち去る、進む
コアイメージ
━━→ → → [方向]
（道に沿ってそのまま進む）

Run along now, I'm busy.

あっちへ行きなさい、忙しいんだ。

The path runs along the river.

その道は川に沿って伸びています。

Point：

「〜に沿って動く」から、子供などに対して「あっちへ行け」と促す決まり文句としても使われます。

run after〜を追いかける
コアイメージ
👤 → → → 🏃
（誰かの後を追って走る）

The boy ran after the bus.

男の子はバスを追いかけました。

The dog is always running after cats.

その犬はいつも猫を追いかけています。

Point：

物理的に誰かや何かの「後ろ（after）」を走る動作そのものです。

run around走り回る、動き回る
コアイメージ
あちこち走り回る
（around = 周辺をぐるぐると）

The kids have been running around all day.

子供たちは一日中走り回っています。

I've been running around trying to get everything ready.

準備のためにあちこち動き回っています。

Point：

目的を持って、あるいは無目的に、周囲を動き回る忙しい様子を表します。

run back走って戻る
コアイメージ
[出発点] ← ← ←
（元いた場所へ急いで戻る）

I had to run back to the house to get my keys.

鍵を取るために家まで走って戻らなければなりませんでした。

Point：

急いで「元の場所（back）」へ戻る動作を表します。

2 日常生活・試験で差がつく表現
run for〜に立候補するTOEIC頻出
コアイメージ
👤 → → → 🏛️ [役職]
目標に向かって走る

She's running for president.

彼女は大統領に立候補しています。

He decided to run for mayor.

彼は市長に立候補することを決めました。

Point：

選挙で「走る」＝「立候補する」という政治用語。ニュースで頻出。

run in the family家系に伝わる、遺伝する
コアイメージ
👨 → 👩 → 👶 [特徴]
家族の中を流れ続ける

Musical talent runs in the family.

音楽の才能は家系に伝わっています。

Heart disease runs in my family.

心臓病は私の家系に遺伝しています。

Point：

特徴や病気が「家族の中を流れる」＝「遺伝する」という表現。

run short of〜が不足するTOEIC頻出
コアイメージ
📦 → 📉 [量が少ない]
短く（不足して）なる

We're running short of time.

時間が不足してきています。

The store is running short of supplies.

その店は在庫が不足しています。

Point：

"run out of"より軽度で、「少なくなってきている」状態を表します。

run counter to〜に反するTOEIC頻出
コアイメージ
━━→ ⚡ ←━━ [対立]
反対方向に走る

This decision runs counter to our policy.

この決定は我々の方針に反しています。

His actions run counter to his words.

彼の行動は言葉に反しています。

Point：

「反対方向に走る」＝「矛盾する」という比喩的表現。フォーマルな文脈で使用。

run the risk of〜の危険を冒すTOEIC頻出
コアイメージ
━━→ ⚠️ [危険]
危険に向かって進む

You run the risk of losing everything.

あなたはすべてを失う危険を冒しています。

We can't run the risk of missing the deadline.

締め切りを逃す危険は冒せません。

Point：

「危険に向かって走る」＝「リスクを取る」という表現。ビジネスで頻出。

run its course自然に終わる
コアイメージ
━━→ → → 🏁
コースを最後まで走り切る

Let the illness run its course.

病気が自然に治るまで待ちましょう。

The conflict will run its course.

その紛争は自然に終わるでしょう。

Point：

「予定されたコースを完走する」＝「自然な終わりを迎える」という表現。

run a fever熱がある
コアイメージ
🌡️ → 📈 [体温上昇]
体内で熱が走る

The child is running a fever.

その子は熱があります。

I've been running a high fever for two days.

2日間高熱が続いています。

Point：

"have a fever"よりやや医学的・客観的な響きがあります。

run late遅れるTOEIC頻出
コアイメージ
⏰ → → → ❌ [遅刻]
遅い状態で走る

Sorry, I'm running late.

すみません、遅れています。

The train is running late today.

今日はお客さんが遅れています。

Point：

現在進行形でよく使われ、「今まさに遅れている」状態を表します。日常会話で頻出。

run on time時間通りに進むTOEIC頻出
コアイメージ
⏰ → ✓ [定刻]
時間通りに走る

The trains usually run on time.

電車は通常時間通りに運行しています。

Does this bus run on time?

このバスは時間通りに来ますか？

Point：

"run late"の反対で、「予定通り」という意味。

run behind schedule予定より遅れるTOEIC頻出
コアイメージ
← ← [現在地]
スケジュールの後ろを走る

The construction is running behind schedule.

建設工事は予定より遅れています。

We're running three weeks behind schedule.

私たちは予定より3週間遅れています。

Point：

ビジネスやプロジェクト管理で頻繁に使われる表現。

run ahead of schedule予定より早く進むTOEIC頻出
コアイメージ
📍 [現在地] → → 📅
スケジュールの前を走る

The project is running ahead of schedule.

プロジェクトは予定より早く進んでいます。

We're running two days ahead of schedule.

私たちは予定より2日早く進んでいます。

Point：

"run behind schedule"の反対で、好ましい状況を表します。

run wild野生化する、荒れ狂う
コアイメージ
→ → → 💥
制御されずに走り回る

Don't let your imagination run wild.

想像力を暴走させないで。

The children are running wild.

子供たちが暴れ回っています。

Point：

「制御なく走る」＝「手に負えない状態」という比喩的表現。

run low少なくなるTOEIC頻出
コアイメージ
📦 → 📉 [低い状態]
低いレベルで走る

Our supplies are running low.

在庫が少なくなってきています。

The fuel tank is running low.

燃料タンクが少なくなってきています。

Point：

"run out"の一歩手前の状態を表します。「まだ残っているが少ない」というニュアンス。

run high（感情が）高まる
コアイメージ
→ 📈 [高い状態]
高いレベルで走る

Emotions are running high.

感情が高ぶっています。

Tensions are running high between the two countries.

両国間の緊張が高まっています。

Point：

主に感情や緊張が「高い状態で推移している」ことを表します。

run deep深く根付いている
コアイメージ
🌊 ↓↓↓ [深層]
深いところを走る

His love for music runs deep.

彼の音楽への愛は深く根付いています。

The problem runs deep.

その問題は根深いです。

Point：

感情や問題が「表面的ではなく深い」ことを強調する表現。

run parallel to〜と並行するTOEIC頻出
コアイメージ
━━━→→→
━━━→→→ [並行]
平行に走る

This street runs parallel to the river.

この通りは川と並行しています。

Our research runs parallel to theirs.

私たちの研究は彼らのものと並行しています。

Point：

物理的な平行だけでなく、比喩的に「同時進行」を表すこともあります。

run contrary to〜に反するTOEIC頻出
コアイメージ
━━→ ⚡ ←━━
反対方向に走る

This runs contrary to our values.

これは我々の価値観に反しています。

His statement runs contrary to the facts.

彼の発言は事実に反しています。

Point：

"run counter to"とほぼ同義。よりフォーマルな響き。

run with〜を採用するTOEIC頻出
コアイメージ
👤 + 💡 → → →
何かと一緒に走る

Let's run with that idea.

そのアイデアを採用しましょう。

The company decided to run with the new strategy.

会社は新しい戦略を採用することにしました。

Point：

「一緒に走る」＝「採用して進める」というビジネス表現。

run to〜に駆けつける、〜に及ぶ
コアイメージ
━━→ → [目的地]
目標に向かって走る

She ran to help him.

彼女は彼を助けに駆けつけました。

The cost could run to millions.

コストは数百万に達する可能性があります。

Point：

物理的な移動と、数量の到達の両方で使われます。

run on続く、延々と話す
コアイメージ
━━→ → → → →
延々と続く

The meeting ran on for hours.

会議は何時間も続きました。

The movie runs on too long.

その映画は長すぎます。

Point：

「終わりなく続く」というネガティブなニュアンスを含むことが多いです。

run off逃げ去る、印刷するTOEIC頻出
コアイメージ
━━→ → 💨
急いで離れる

The thief ran off with the money.

泥棒はお金を持って逃げ去りました。

Could you run off 20 copies?

20部コピーしてもらえますか？

Point：

文脈によって意味が大きく変わる多義語です。

run out on見捨てる、裏切る
コアイメージ
👤 ← 💔 → → 👤
相手を残して逃げ出す

He ran out on his family.

彼は家族を見捨てました。

Don't run out on me now.

今、私を見捨てないで。

Point：

「逃げ出して相手を置き去りにする」という強い非難のニュアンスを含みます。

3 ビジネス・上級表現
run a business事業を経営するTOEIC頻出
コアイメージ
💼 ━━→→→
事業を継続的に動かす

She has been running a business for ten years.

彼女は10年間事業を経営しています。

Running a business requires a lot of hard work.

事業を経営するには多大な努力が必要です。

Point：

規模に関わらず「経営する」を意味する最も一般的な表現。

run a company会社を経営する
コアイメージ
🏢 ━━→→→
会社全体を動かす

He runs a global IT company.

彼はグローバルなIT会社を経営しています。

Who is actually running the company?

実際に会社を運営しているのは誰ですか？

Point：

組織としての「会社」を運営することに焦点を当てた表現。

run an organization組織を運営する
コアイメージ
👥 ━━→→→
組織を機能させる

She runs a non-profit organization.

彼女は非営利組織を運営しています。

そのような大きな組織を運営するのは難しいです。

Point：

NGO、NPO、団体などの「組織」全般に使われます。

run a department部署を管理・運営するTOEIC頻出
コアイメージ
📂 ━━→→→
部署の業務を回す

He runs the sales department efficiently.

彼は営業部を効率的に運営しています。

She was chosen to run the marketing department.

彼女はマーケティング部を任されることになりました。

Point：

特定の「部署」や「部門」の責任者として運営することを表します。

run a projectプロジェクトを運営するTOEIC頻出
コアイメージ
📝 ━━→→→
プロジェクトを進行させる

They are running a pilot project in Asia.

彼らはアジアでパイロットプロジェクトを運営しています。

We need someone experienced to run this project.

このプロジェクトを運営するには経験豊かな人が必要です。

特定の「プロジェクト」の進行や管理を責任持って行うこと。

彼女は会議を効果的に進行させる方法を知っています。

run a programプログラムを実行・運営するTOEIC頻出
コアイメージ
💻 ━━→→→
プログラムを作動させる

毎年夏にインターンシッププログラムを運営しています。

コアイメージ
🧪 ━━→→→

彼らは植物の成長に関する実験を行っています。

Scientists are running an experiment in the lab.

科学者たちは研究所で実験を行っています。

システムがセキュリティチェックを行います。

run an advertisement / run an ad広告を出す、掲載するTOEIC頻出
