GO Phrasal Verbs

GO 句動詞 完全解説

基本イメージから日常会話表現まで（Section 0〜1）

🎯 GOのコアイメージ

本質：「起点から離れる動き」
● ━━━━━→
（今いる場所から遠ざかる）
行く
現在地から離れて移動
進む
現在地から前方へ離れる
悪くなる
良い状態から離れる
消える
存在場所から離れる

Section 0: 超頻出・高校生から必須（最優先）

Core Phrasal Verb

go up

上がる、増加する
コアイメージ：「上方向へ」離れて進む
● 上（上昇）
↑ up
━━━━━ 下
Usage Examples
Go up the stairs. 階段を上がって。（階段を上方向へ進んで）
Prices are going up. 価格が上がっている。（価格が上方向へ進んでいる）
Sales went up by 20%. 売上が20%上昇した。（売上が20%上方向へ進んだ）
Important Points

up = 上方向。go down（下がる）の反対。

Core Phrasal Verb

go down

下がる、沈む、減少する
コアイメージ：「下方向へ」離れて進む
●（高い位置）
↓ down
━━━━━ 下
Usage Examples
The sun went down. 太陽が沈んだ。（太陽が下方向へ進んだ）
The fever went down. 熱が下がった。（熱が下方向へ進んだ）
His reputation went down. 彼の評判が落ちた。（彼の評判が下方向へ進んだ）
Important Points

down = 下方向。「減少・悪化」のニュアンス。

Core Phrasal Verb

go out

外出する、消える、交際する
コアイメージ：内部から「外へ離れる」
[内部] ━━→ 外部
（out = 外へ）
Usage Examples
Let's go out tonight. 今夜出かけよう。（家の内部から外へ離れよう）
The light went out. 明かりが消えた。（点灯状態から離れて消灯状態へ）
Are they going out? 彼らは付き合ってるの？（彼らは一緒に外出する関係か）
Important Points

out = 外へ。「内から外への移動」。

Core Phrasal Verb

コアイメージ：外部から「内部へ」離れて入る
外部 ━━→ [内部]

Usage Examples

Important Points

Core Phrasal Verb

go back

戻る、さかのぼる
コアイメージ：「後ろへ離れていく」= 元に戻る
現在 ━━━━→ 過去（元の位置）
（back = 戻る）
Usage Examples
Let's go back home. 家に戻ろう。（元の場所（家）へ後ろ向きに進もう）
I need to go back. 戻らなければならない。（元の場所へ後ろ向きに進む必要がある）
This tradition goes back 100 years. この伝統は100年前にさかのぼる。（この伝統が時間的に後ろへ100年進む）
Our friendship goes back to college. 私たちの友情は大学時代にさかのぼる。（友情が大学時代まで後ろへ進む）
Let's go back to the main topic. 本題に戻りましょう。（本題へ後ろ向きに進みましょう）
Important Points

back = 後ろ・元の位置。時間的・空間的な「復帰」。

Core Phrasal Verb

Important Points

on = 接触・継続。「進行し続ける」イメージ。

Core Phrasal Verb

go off

爆発する、鳴る、腐る、立ち去る
コアイメージ：正常な状態から「離れる」変化
正常 ━━━━→ 異常
（off = 分離）
Usage Examples
The bomb went off. 爆弾が爆発した。（静止状態から離れて爆発状態へ）
My alarm went off at 6. アラームが6時に鳴った。（静止状態から離れて作動状態へ）
The fire alarm went off. 火災報知器が鳴った。（静止状態から離れて警報状態へ）
The meat has gone off. 肉が腐った。（新鮮な状態から離れて腐敗状態へ）
This milk has gone off. この牛乳は腐っている。（牛乳が良い状態から離れている）
He went off in anger. 彼は怒って立ち去った。（その場から離れて去った）
Important Points

off = 分離・離脱。「正常から異常への離脱」。

Core Phrasal Verb

go + -ing

〜しに行く
コアイメージ：活動の場所へ「離れて行く」
I go swimming every week.
毎週泳ぎに行きます。
→ ここから離れて水泳という活動へ
Usage Examples

go + -ing は「レジャー・スポーツ活動」に使う。通勤・通学は go to work / go to school。

Core Phrasal Verb

go + 形容詞

〜になる
コアイメージ：現在の状態から「離れて」別の状態へ

牛乳が腐った。
→ 良い状態から離れて悪い状態へ
Usage Examples
She went crazy. 彼女は気が狂った。（正常な状態から離れて異常な状態へ）

Frequent adjectives: go bad, go wrong, go mad, go blind, go deaf, go pale, go red
Important Points

goは「悪化」のニュアンスが強い。become（中立的な変化）との違いに注意。

Standard Phrasal Verb

A + B ━━━→
